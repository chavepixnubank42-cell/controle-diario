Política de Privacidade

Aplicativo Controle Diário — última atualização:

Esta política explica, de forma simples e direta, quais dados o aplicativo Controle Diário acessa, por quê, e o que acontece com eles.

Resumo rápido

  • Todos os seus dados ficam salvos apenas no seu próprio celular. O app não tem servidor, não tem conta de usuário e não envia nada para a internet.
  • Não usamos anúncios, não usamos ferramentas de rastreamento/analytics de terceiros e não vendemos ou compartilhamos dados com ninguém.
  • Você pode apagar todos os seus dados a qualquer momento, direto no app.

Quais dados o app acessa e por quê

Localização (GPS) — usada apenas enquanto você tem um dia de trabalho ativo no app, para calcular automaticamente a quilometragem percorrida. Essa localização:

  • É processada inteiramente no seu aparelho;
  • Nunca é enviada para nenhum servidor, nem armazenada como um histórico de rotas — o app guarda apenas a distância total calculada, não o trajeto;
  • É opcional: se você não conceder a permissão, o app continua funcionando normalmente, só não mostra o contador automático de KM (você pode digitar o KM manualmente).

Câmera e galeria de fotos — usadas apenas quando você opta por anexar uma foto a um registro de entrega. As fotos:

  • Ficam salvas apenas no armazenamento local do seu celular;
  • Nunca são enviadas para a internet;
  • São excluídas automaticamente se você excluir a entrega correspondente.

Dados que você digita no app — nome de clientes, valores de entregas, despesas, metas, configurações. Tudo isso é armazenado apenas localmente no seu aparelho, da mesma forma que as fotos.

Backup manual

O app oferece uma opção de "Exportar backup" nas configurações, que gera um arquivo com os seus dados para você guardar onde quiser (por exemplo, no seu Google Drive). Esse arquivo é gerado e salvo pelo seu próprio celular — nós não temos acesso a ele.

Compartilhamento de dados

Não compartilhamos, vendemos ou transmitimos nenhum dado seu para terceiros, porque simplesmente não temos acesso a esses dados — eles nunca saem do seu aparelho.

Exclusão de dados

Você pode excluir entregas, despesas ou clientes individualmente dentro do app a qualquer momento. Para apagar todos os dados de uma vez, basta desinstalar o aplicativo do seu celular.

Crianças

Este aplicativo é destinado a entregadores maiores de idade e não foi desenvolvido para uso por crianças.

Alterações nesta política

Se esta política mudar no futuro, a data de "última atualização" no topo desta página será revisada.
